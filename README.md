# 展示外壳曲面偏置工作台

给定合成曲面与目标厚度，生成内外壳或等价实体表示，并在网页端检查壁厚、开口与失败区域。
生成的厚度由**独立的射线测厚**在输出网格上实测，不读取生成用的距离场；原始资产始终只读。

## 图形入口（主入口）

展示外壳以图形界面为主入口，命令行仅起辅助作用（安装依赖、测试与基准）：

```bash
npm install
npm run dev      # → http://localhost:5173  展示外壳图形界面
```

生产构建与预览：

```bash
npm run build
npm run preview  # → http://localhost:5174
```

测试（含 4 个验收夹具）：

```bash
npm test         # vitest run
npm run typecheck
```

浏览器需支持 WebGL。若无法创建 WebGL 上下文，页面会明确提示，生成、参数保存与导出仍然可用。

## 外壳查询基准（辅助命令行）

局部相交加速的正确性与成本基准，不入常规测试：

```bash
npm run bench    # vitest run --config vitest.bench.config.ts
```

基准覆盖：薄壳凹角壳体（凹槽块 / 薄颈的管线输出）、间隙远小于三角形尺寸的平行薄片、
凹角处带穿插鳍板的槽体，以及对凹槽块壳体连续 6 轮局部改形（每轮把外表面局部压过内表面，
制造真实自交）。每个用例记录**相交候选数**、精确判定对数、相交对数、**漏检率**与误报率
（对照保留的 BVH 参考实现，小网格另对照 O(n²) 暴力全量参考），并给出成本分解
（索引构建 / 候选生成 / 精确判定 / 合计 vs 参考合计）。漏检率或误报率不为 0 时基准直接失败，
不会用默认值遮掩错误。

局部相交加速的计算顺序（基准与内核一致）：

1. 对输出网格建立保守均匀网格索引：每个三角形 AABB 插入其覆盖的所有网格单元；
   相交必然包围盒重叠，重叠必然共享单元，因此候选集恰好是包围盒重叠对——薄片与凹角不会被漏。
2. 候选对按“重叠区最小角所在单元”唯一发射，无需去重集合；共享顶点的拓扑邻居跳过。
3. 每个候选对跑与参考实现完全相同的精确判定（共面重叠面积 / 非共面穿越线段），全量执行不设上限。
4. 与完整参考求解（保留的 bvhcast 实现，取消对数上限）逐对比较失败区域，漏检率须为 0；
   加速路径完整执行之后，才进行速度对比。
5. 局部改形后：仅对受影响三角形重算包围盒并重哈希（`updateTriangles`），只重测涉及它们的候选对，
   未受影响的判定结果保留，合并结果与全量重查一致（`detectSelfIntersectionsAfterEdit`）。

当前证据（`npm run bench` 输出，2026-11 本机）：凹槽块壳体 61k 三角形全量查询 78ms vs 参考 3864ms
（约 49×），薄颈壳体 84k 三角形 77ms vs 4720ms（约 62×）；6 轮局部改形增量合计 32ms vs
全量重建 584ms vs 参考 21648ms；全部用例漏检率 0、误报率 0。

## 界面

- **左栏**：夹具选择、内核参数（偏置模式 / 厚度 / 距离场分辨率 / 测厚采样密度）、开放曲面的空气侧、显示开关、参数保存/载入、结果导出。
- **中栏**：Three.js 视口。半透明灰色为原始曲面（只读），蓝/橙/绿为输出壳体的外表面/内表面/边缘；红点为失败与吞并区域，紫点为尖角与边界附近被排除的探针；短线段是每条测厚探针的实测跨距。
- **右栏**：总体结论、逐项核验、实测壁厚统计与直方图、几何变化记录、细部吞并报告、输出网格信息、算法适用限制。

参数修改后结果会标记为“过期”，点击“生成外壳”重新运行。

## 算法与适用限制

1. **距离场窄带**：用 BVH 最近点求无符号距离；闭合输入用逐行射线奇偶定符号，开放输入用显式选择的空气侧 + 局部面法向定符号。
2. **带选择**：向内 `[-t, 0]`、向外 `[0, t]`、对称 `[-t/2, t/2]`。
3. **等值面提取**：Surface Nets 直接在零交叉边取点，不做后置牛顿投影——在三角化场上投影会沿切向漂移并增大误差（实测球壳顶点误差反而从约 0.02 增至 0.18 模型单位）。
4. **开放曲面**：偏置带会在边界处绕成圆角端盖。内核沿输入边界显式裁掉端盖三角形，保留原有开口与边界环；该裁剪计入变化记录，不做静默删除。
5. **测厚**：在输出网格的外/内表面之间取最近点间距（最小壁厚），按法线夹角排除折叠区域，并按到输入尖边/边界的距离排除圆角影响区；所有排除都计入统计并显示。
6. **自交**：保守均匀网格空间索引筛出包围盒重叠的候选三角形对（相交必然重叠，故不漏对；薄片与凹角不受影响），再逐对精确判定；共享顶点或边的拓扑邻居不计；共面三角形用投影后真实重叠面积判定，避免 three.js 共面求交的伪边。候选集全量判定、不设上限；原 BVH 逐对实现保留为参考（`detectSelfIntersectionsReference`），基准与测试逐对核对两者失败区域一致。局部改形后索引增量维护，仅重测受影响区域。
7. **吞并检测**：沿偏置方向从表面探针出发，若对面朝向相反的表面距离小于两侧偏置量之和（`2 × 偏置量`），判定该处细部会被合并/吞并，并在视口标出。
8. **场级拓扑**：粗奇偶网格统计输出封闭空腔；封闭输入预期会产生 1 个壳体空腔，只有超出预期的空腔才作为“新封闭空气”报告。

已知近似：距离场偏置在尖锐凸角处会圆化、凹角处会填补；分辨率过低时薄壁偏差增大。这些是所选算法的固有属性，结果区会以核验项和限制说明如实反映，不会用表面着色深浅冒充厚度正确，也不作任何实物强度保证。

## 验收夹具

| 夹具 | 预期 | 检查点 |
| --- | --- | --- |
| 球壳 `solid-sphere` | 已知壁厚 2.5 | 中位壁厚、闭合、无自交、内外关系 |
| 凹槽块 `grooved-block` | 尖角与凹槽 | 壁厚中位、闭合、角部排除计数 |
| 薄颈 `thin-neck` | 特征吞并 | 安全厚度通过；接近颈半径时触发吞并警告 |
| 开口片 `open-sheet` | 开放边界 | 输出保持开口、不推断内部、需显式空气侧 |

## 原始资产

输入网格在生成前会复制到 BVH 缓冲区，并在结束时对比 FNV-1a 几何哈希；所有方向修正、裁剪与投影只作用于内存副本。保存参数只写 JSON（`display-shell-params.v1`），不写几何；导出下载的是当前生成的结果网格。原始夹具文件本身不会被覆盖。
