# 展示外壳曲面偏置工作台

给定合成曲面与目标厚度，生成内外壳或等价实体表示，并在网页端检查壁厚、开口与失败区域。
生成的厚度由**独立的射线测厚**在输出网格上实测，不读取生成用的距离场；原始资产始终只读。

## 启动

```bash
npm install
npm run dev      # → http://localhost:5173
```

生产构建与预览：

```bash
npm run build
npm run preview  # → http://localhost:5174
```

测试（含 4 个验收夹具）：

```bash
npm test         # vitest run
npm run typecheck
```

浏览器需支持 WebGL。若无法创建 WebGL 上下文，页面会明确提示，生成、参数保存与导出仍然可用。

## 界面

- **左栏**：夹具选择、内核参数（偏置模式 / 厚度 / 距离场分辨率 / 测厚采样密度）、开放曲面的空气侧、显示开关、参数保存/载入、结果导出。
- **中栏**：Three.js 视口。半透明灰色为原始曲面（只读），蓝/橙/绿为输出壳体的外表面/内表面/边缘；红点为失败与吞并区域，紫点为尖角与边界附近被排除的探针；短线段是每条测厚探针的实测跨距。
- **右栏**：总体结论、逐项核验、实测壁厚统计与直方图、几何变化记录、细部吞并报告、输出网格信息、算法适用限制。

参数修改后结果会标记为“过期”，点击“生成外壳”重新运行。

## 算法与适用限制

1. **距离场窄带**：用 BVH 最近点求无符号距离；闭合输入用逐行射线奇偶定符号，开放输入用显式选择的空气侧 + 局部面法向定符号。
2. **带选择**：向内 `[-t, 0]`、向外 `[0, t]`、对称 `[-t/2, t/2]`。
3. **等值面提取**：Surface Nets 直接在零交叉边取点，不做后置牛顿投影——在三角化场上投影会沿切向漂移并增大误差（实测球壳顶点误差反而从约 0.02 增至 0.18 模型单位）。
4. **开放曲面**：偏置带会在边界处绕成圆角端盖。内核沿输入边界显式裁掉端盖三角形，保留原有开口与边界环；该裁剪计入变化记录，不做静默删除。
5. **测厚**：在输出网格的外/内表面之间取最近点间距（最小壁厚），按法线夹角排除折叠区域，并按到输入尖边/边界的距离排除圆角影响区；所有排除都计入统计并显示。
6. **自交**：逐对三角形检测；共享顶点或边的拓扑邻居不计；共面三角形用投影后真实重叠面积判定，避免 three.js 共面求交的伪边。
7. **吞并检测**：沿偏置方向从表面探针出发，若对面朝向相反的表面距离小于两侧偏置量之和（`2 × 偏置量`），判定该处细部会被合并/吞并，并在视口标出。
8. **场级拓扑**：粗奇偶网格统计输出封闭空腔；封闭输入预期会产生 1 个壳体空腔，只有超出预期的空腔才作为“新封闭空气”报告。

已知近似：距离场偏置在尖锐凸角处会圆化、凹角处会填补；分辨率过低时薄壁偏差增大。这些是所选算法的固有属性，结果区会以核验项和限制说明如实反映，不会用表面着色深浅冒充厚度正确，也不作任何实物强度保证。

## 验收夹具

| 夹具 | 预期 | 检查点 |
| --- | --- | --- |
| 球壳 `solid-sphere` | 已知壁厚 2.5 | 中位壁厚、闭合、无自交、内外关系 |
| 凹槽块 `grooved-block` | 尖角与凹槽 | 壁厚中位、闭合、角部排除计数 |
| 薄颈 `thin-neck` | 特征吞并 | 安全厚度通过；接近颈半径时触发吞并警告 |
| 开口片 `open-sheet` | 开放边界 | 输出保持开口、不推断内部、需显式空气侧 |

## 原始资产

输入网格在生成前会复制到 BVH 缓冲区，并在结束时对比 FNV-1a 几何哈希；所有方向修正、裁剪与投影只作用于内存副本。保存参数只写 JSON（`display-shell-params.v1`），不写几何；导出下载的是当前生成的结果网格。原始夹具文件本身不会被覆盖。
